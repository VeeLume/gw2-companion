# GW2 Companion

A Guild Wars 2 companion application built with Tauri + SolidJS.

## Architecture

Cargo workspace monorepo with four crates:

- **`crates/gw2-api-macros`** — Proc macro crate
  - Single unified macro `#[gw2_endpoint(...)]` covering all endpoint shapes
  - `#[gw2_enum]` for flat string enums with `Unknown(String)` catch-all
  - `#[gw2_tagged_union]` for JSON `"type"`-dispatched enums

- **`crates/gw2-api`** — GW2 API v2 wrapper library
  - Type-safe client with typed IDs (`ItemId`, `RecipeId`, etc.) auto-generated by `#[gw2_endpoint(id_type = u32)]`
  - Type-level auth states: `Gw2Client<Unauthenticated>` vs `Gw2Client<Authenticated>`
  - Builder-pattern endpoint navigation: `client.items().get(id)`, `client.commerce().prices()`
  - Async-first with reqwest, moka LRU cache (5-min TTL), governor GCRA rate limiter
  - Rich models with `#[gw2_tagged_union]` for item/achievement variants
  - `Coin` type with gold/silver/copper display
  - Patch system for permanent GW2 API data bugs (`Patchable` trait, `patches/` modules)
  - Endpoint registry via `linkme` distributed slices (used by CLI)

- **`crates/gw2-api-cli`** — Developer CLI (`cargo run -p gw2-api-cli -- <cmd>`)
  - `list [--diff]` — list registered endpoints; diff against live `/v2.json`
  - `single [--endpoint PATH|--all] [--keep-going]` — single-test each endpoint
  - `full [--endpoint PATH|--all] [--concurrency N]` — full data fetch + deserialization

- **`crates/gw2-db`** — SQLite persistence layer *(not yet implemented)*
  - rusqlite with bundled SQLite
  - Will manage cached API data, user goals, checklists

- **`src-tauri/`** — Tauri v2 backend
  - Tauri commands exposing API + DB to the frontend
  - State management via Tauri's managed state

- **`src/`** — SolidJS + TypeScript frontend
  - Vite-based build
  - Communicates with Rust backend via `@tauri-apps/api`

## Features (v1)

1. **Legendary Crafting Tracker** — Track materials, precursors, and crafting progress
2. **Achievement Tracker** — Browse achievements with dependency trees
3. **Trading Post Tools** — Price lookups, flipping analysis
4. **Daily/Weekly Checklist** — Dailies, weeklies, wizard's vault tasks

## GW2 API v2

- Base URL: `https://api.guildwars2.com/v2`
- Auth: Bearer token via `Authorization` header
- Bulk: `?ids=1,2,3` or `?ids=all`, pagination `?page=N&page_size=M` (max 200)
- Rate limit: ~300 req/min (429 on exceeded)
- Schema versioning: `?v=<ISO8601>` or `?v=latest`; default `2025-08-29T01:00:00.000Z`
- Language: `?lang=en|de|es|fr|zh`

## Macro System

All endpoint types use the single unified `#[gw2_endpoint(...)]` macro. The old separate macros (`#[gw2_resource]`, `#[gw2_singleton]`, `#[gw2_collection_singleton]`, `#[gw2_namespace]`, `#[gw2_method]`) are removed and emit compile errors.

### `#[gw2_endpoint]` flags

| Flag | Effect |
|------|--------|
| `path = "..."` | API path (required). Slash-separated; drives accessor chain and struct naming. |
| `id_type = u32` | Generates `TypeNameId(u32)` newtype + `Resource` impl. Omit for singletons/collections. |
| `paged` | Adds `PagedResource` impl (enables `pages()` / `all()`). |
| `collection` | Fixed-URL endpoint returning `Vec<T>`. |
| `nullable` | With `collection`: returns `Vec<Option<T>>` (e.g. `/v2/account/bank`). |
| `namespace` | Navigation-only handle; generates an accessor but no `.get()`. |
| `auth` | Marks endpoint as auth-required; accessor on `Gw2Client<Authenticated>`. |
| `no_registry` | Suppress registry entry (use on error/fallback paths). |
| `no_default_patch` | Suppress generated no-op `Patchable` impl (for types with custom patches). |
| `accessor = ident` | Override the generated accessor method name. |
| `no_accessor` | Suppress accessor generation. |
| `no_trait` | Suppress trait impl generation. |
| `also("path2", ...)` | Register additional paths pointing to the same struct. |

On **async functions**: `#[gw2_endpoint(path = "...")]` attaches the fn to the endpoint struct inferred from the second-to-last path segment. Supports `test_params(key = expr)` for registry smoke tests.

## Implemented Endpoints (`crates/gw2-api/src/endpoints/`)

Use the gw2-api-cli to list all implemented endpoints `cargo run -p gw2-api-cli -- list`

## Conventions

- Use `thiserror` for library error types, `anyhow` in the Tauri app layer
- All API types derive `Debug, Clone, Serialize, Deserialize`
- Typed IDs are auto-generated newtypes: `pub struct ItemId(pub u32);`
- Endpoints return `Result<T, Gw2ApiError>`
- Tauri commands are `async` and return `Result<T, String>` (Tauri convention)
- Frontend uses TypeScript strict mode
- CSS via Tailwind CSS
- `extern crate self as gw2_api` in `crates/gw2-api/src/lib.rs` — required for proc macro path resolution inside the crate

## Development

```bash
# Install frontend deps
npm install

# Run dev mode (starts both Tauri + Vite)
cargo tauri dev

# Build for release
cargo tauri build

# Run API crate tests
cargo test -p gw2-api

# Verify data patches against live API
cargo test -p gw2-api --features verify-patches

# CLI — list endpoints / diff against /v2.json
cargo run -p gw2-api-cli -- list --diff

# CLI — smoke-test all endpoints
cargo run -p gw2-api-cli -- single --all

# CLI — full data fetch (slow)
cargo run -p gw2-api-cli -- full --all --concurrency 8
```
